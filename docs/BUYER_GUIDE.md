# Руководство покупателя (BUYER_GUIDE)

Поздравляем с приобретением исходного кода **mangal-site** — готового продаваемого решения для заведений общественного питания и доставок еды!

---

## 1. Состав продукта

Покупатель получает полный исходный код монорепозитория, включающий:
1. **Storefront (Витрина)**: Высокопроизводительное веб-приложение на Next.js (React 19) с адаптивным дизайном, выбором блюд, корзиной, оформлением заказа и отслеживанием статусов.
2. **Platform API & Admin (Платформа и Админка)**: Бэкенд и панель управления для ресторана (управление товарами, категориями, ценами, параметрами заведения, заказами и статусами).
3. **База данных PostgreSQL & Prisma ORM**: Готовая схема базы данных с миграциями, шифрованием ПД и валидацией контрактов Zod.
4. **Docker & VPS деплой**: Готовый `docker-compose.yml`, Caddy reverse proxy с автоматическим HTTPS и скрипты автоматической установки.
5. **Система резервного копирования**: Скрипты бекапа и восстановления базы данных с контролем хранения архивов.

---

## 2. Архитектура системы

- **Монорепозиторий**: Управляется через npm workspaces (`apps/storefront`, `apps/platform`, `packages/contracts`, `packages/design-system`).
- **Схема развёртывания**: Модель **Single-Tenant** (один VPS — одна база — один сайт для одного заведения). Это обеспечивает 100% изоляцию данных клиентов, соблюдение законодательства о персональных данных и независимость серверов.
- **Хранение медиа-файлов**: Загруженные фотографии хранятся в постоянном Docker volume (`uploadsdata`) и отдаются напрямую через HTTP reverse proxy.

## 3. Быстрый запуск

### Локальная проверка (Windows / macOS / Linux)
Для детальной информации смотрите [`LOCAL_WINDOWS.md`](../LOCAL_WINDOWS.md).
Команда запуска:
```bash
npm run demo:local
```

### Развёртывание на VPS
Для детальной инструкции смотрите [`VPS_DEPLOY.md`](./VPS_DEPLOY.md).
Команда установки на чистом Ubuntu VPS:
```bash
./scripts/install-vps.sh
```

## 4. Кастомизация и настройка бренда

Вся конфигурация бренда (название кафе, цвета темы, контакты, меню, категории и блюда) настраивается без изменения исходного кода приложения:
- Через панель администратора в разделе `/admin/settings`;
- Либо через скрипт заведения [`scripts/create-client.ts`](../scripts/create-client.ts).

Подробное руководство по настройке смотрите в [`CONSTRUCTOR_GUIDE.md`](./CONSTRUCTOR_GUIDE.md).

---

## 5. Обновление версии

Для выпуска обновлений для клиентов:
1. Выполните `git pull origin production-russia-vps` на сервере.
2. Запустите перезапуск контейнеров и миграцию:
   ```bash
   docker compose up -d --build
   docker compose exec platform npx prisma migrate deploy
   ```

## 6. Известные особенности и ограничения

Подробный технический реестр приведен в [`KNOWN_ISSUES.md`](./KNOWN_ISSUES.md). Основные моменты:
- Продукт предназначен строго для модели 1 заведение = 1 VPS (не мультитентенантный SaaS).
- Все секреты генерируются индивидуально для каждого клиента и хранятся в нетрекаемом `.env`.
