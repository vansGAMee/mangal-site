# Диагностика и устранение неисправностей (TROUBLESHOOTING)

Данный документ содержит решения распространённых проблем при локальном запуске и развёртывании на VPS.

---

## 1. Проблемы при локальном запуске (Windows)

### Ошибка: «Docker не найден или не запущен»
- **Причина**: Служба Docker Desktop не запущена или находится в процессе инициализации.
- **Решение**: Откройте Docker Desktop, дождись статуса `Engine Running` (зеленый индикатор в углу) и повторно запустите `START_DEMO.cmd`.

### Ошибка: «Порт 3000 / 3001 / 55432 занят»
- **Причина**: На компьютере уже запущен другой экземпляр приложения или PostgreSQL.
- **Решение**: Завершите предыдущие процессы Node.js или контейнер демо-базы командой:
  ```powershell
  docker compose -p mangal-local-demo stop postgres
  ```

---

## 2. Проблемы при развёртывании на VPS

### Ошибка: «DOMAIN is required in .env»
- **Причина**: Файл `.env` не содержит переменную `DOMAIN`.
- **Решение**: Запустите мастер генерации `.env`:
  ```bash
  bash scripts/setup-client-env.sh
  ```
  Укажите домен (например, `mycafe.ru`).

### Ошибка: «POSTGRES_PASSWORD is required in .env»
- **Причина**: В `.env` отсутствует пароль базы данных.
- **Решение**: Укажите случайный пароль в переменной `POSTGRES_PASSWORD` в `.env`.

### Caddy возвращает 502 Bad Gateway
- **Причина**: Контейнеры `platform` или `storefront` еще не завершили запуск или не прошли healthcheck.
- **Решение**: Проверьте логи сервисов командой:
  ```bash
  docker compose logs -f platform
  docker compose logs -f storefront
  ```

---

## 3. Сброс и восстановление доступа администратора

Если утеряны учетные данные или двухфакторный ключ TOTP администратора, выполните на VPS:

```bash
docker compose exec -it platform npm run admin:create -- --force
```

Введите новые email и пароль. Старые сессии и TOTP-ключ будут безопасно аннулированы, и выведется новый QR/TOTP URI.
