# Руководство по резервному копированию и восстановлению (BACKUP_RESTORE)

Данный документ содержит полные инструкции по созданию и восстановлению резервных копий базы данных PostgreSQL и пользовательских файлов.

---

## 1. Резервное копирование на VPS (Production)

Для создания резервной копии на Ubuntu VPS выполните из корня проекта:

```bash
./scripts/backup-vps.sh
```

Скрипт автоматически:
1. Выполнит `pg_dump` базы данных PostgreSQL внутри контейнера;
2. Создаст сжатый архив загруженных изображений (`/app/uploads`);
3. Сохранит архивы в папку `./backups/` с меткой даты и времени (например, `mangal-db-20260804-165000.dump`);
4. Выполнит ротацию старых копий (по умолчанию сохраняются 10 последних архивов, значение меняется через `MAX_BACKUPS=20`).

---

## 2. Восстановление из резервной копии на VPS (Production)

Чтобы восстановить состояние базы данных на VPS из файла архива, выполните:

```bash
./scripts/restore-vps.sh ./backups/<FILENAME>.dump mangal
```

Пример:
```bash
./scripts/restore-vps.sh ./backups/mangal-db-20260804-165000.dump mangal
```

Скрипт выполнит:
1. Валидацию наличия и размера дампа;
2. Временную остановку приёмников трафика (`platform`, `storefront`);
3. Восстановление данных PostgreSQL с ключами `--clean --if-exists`;
4. Запуск сервисов платформы и витрины.

---

## 3. Локальное резервное копирование (Development / Windows)

Для локального бэкапа (если установлен клиент PostgreSQL или через npm):

```bash
npm run db:backup
```

Для локального восстановления:

```bash
npm run db:restore -- --file ./backups/<FILENAME>.dump --confirm mangal
```
