# Регламент запуска нового клиента / заведения (CLIENT_INSTALLATION)

Данный документ описывает стандартный порядок действий для технического специалиста по подключению нового заведения на отдельный сервер (Single-Tenant VPS).

---

## 1. Чек-лист сбора данных от клиента

Перед началом развёртывания запросите у владельца заведения:

1. **Доменное имя** (например, `bbq-mangal.ru`), зарегистрированное у любого регистратора;
2. **Email администратора** для доступа в панель управления;
3. **Название заведения** и контактный номер телефона;
4. **Адрес кафе** и условия доставки;
5. **Файл меню** (CSV / JSON) или список блюд с ценами и фотографиями;
6. **Реквизиты заведения** (ИНН, ОГРН, Юридический адрес) для размещения в разделе «Правовая информация».

---

## 2. Пошаговый процесс развёртывания

### Шаг 1. Аренда и подготовка VPS
- Закажите VPS у любого российского провайдера (Reg.ru, Timeweb, Selectel, VDSina и т.д.);
- Установите Ubuntu 22.04 LTS / 24.04 LTS;
- Привяжите A-запись домена клиента к IP-адресу VPS.

### Шаг 2. Запуск авто-инсталлятора
Подключитесь к VPS по SSH и запустите:

```bash
git clone https://github.com/vansGAMee/mangal-site.git client-deployment
cd client-deployment
git checkout production-russia-vps

./scripts/install-vps.sh
```

Укажите домен, email администратора и название заведения.

### Шаг 3. Создание аккаунта администратора
```bash
docker compose exec -it platform npm run admin:create
```

### Шаг 4. Импорт меню и первоначальное наполнение
Вы можете импортировать готовое меню из CSV/JSON файла командой:

```bash
docker compose exec platform npm run import-menu -- --file ./examples/menu-template.json
```

Или заполнить меню вручную через админку `https://client-domain.ru/admin`.

---

## 3. Финальная проверка перед сдачей клиенту

1. Перейдите на сайт заведения по домену `https://client-domain.ru`;
2. Проверьте корректность работы SSL-сертификата (HTTPS);
3. Добавьте товар в корзину и оформите тестовый заказ;
4. Убедитесь, что заказ отобразился в админке `https://client-domain.ru/admin`;
5. Смените статус заказа и проверьте обновление на странице клиентов;
6. Передайте клиенту логин, пароль и TOTP-ключ доступа в админку.
