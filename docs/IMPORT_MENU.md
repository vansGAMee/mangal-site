# Импорт меню

Поддерживаются CSV и JSON с полями:

`category`, `name`, `description`, `price`, `oldPrice`, `weight`, `image`, `available`, `sortOrder`.

Цены указываются в рублях и преобразуются в целые копейки без арифметики с плавающей точкой. Пустая `price` создаёт позицию «Цена уточняется», которую нельзя заказать. `weight` — подтверждённый вес порции в граммах.

## Проверка без записи

```bash
npm run import-menu -- --file ./examples/menu-template.csv --dry-run
```

## Импорт

```bash
npm run import-menu -- --file ./menu.csv
```

Импорт выполняется одной транзакцией. SHA‑256 файла сохраняется в `CatalogImport`, поэтому тот же файл нельзя применить повторно. Существующие товары по slug пропускаются, чтобы не затереть изменения владельца в админке.

Только при явном решении обновить существующие позиции:

```bash
npm run import-menu -- --file ./menu.csv --update-existing
```

В CSV поддерживаются запятые, переносы строк и двойные кавычки внутри quoted-полей. Ошибки содержат номер строки. В `image` разрешён только локальный `/path`. Реальную фотографию после импорта загрузите через админку: приложение проверит размер, MIME и сигнатуру и сохранит файл в выбранном постоянном хранилище. Это не позволяет случайному внешнему домену получать IP посетителей.
