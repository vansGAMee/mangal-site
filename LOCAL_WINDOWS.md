# Инструкция по локальному запуску на Windows

Данный документ описывает процесс быстрой проверки и демонстрации проекта на компьютере под управлением Windows.

## Требования к системе

1. **Windows 10 / 11** (с установленным PowerShell 5.1+).
2. **Node.js 24 LTS** (npm 11+).
3. **Docker Desktop** (запущенный в режиме Linux containers).

## Быстрый запуск (один клик)

1. Убедитесь, что Docker Desktop запущен.
2. Двойным кликом запустите файл `START_DEMO.cmd` в корневой папке проекта.
3. Скрипт автоматически:
   - Проверит окружение;
   - Запустит изолированный PostgreSQL контейнер на порту `55432`;
   - Применит миграции базы данных и импортирует демо-меню;
   - Запустит Platform API (порт 3001) и Storefront (порт 3000);
   - Откроет браузер на `http://localhost:3000`.

## Альтернативный запуск из терминала

Вы можете запустить демо-режим командой `npm`:

```cmd
npm run demo:local
```

или напрямую через PowerShell:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\demo-local.ps1
```

## Создание учетной записи администратора

Для входа в панель управления админки (`http://localhost:3001/admin`) выполните в отдельном окне консоли:

```cmd
npm run admin:create
```

Введите email и пароль (от 14 символов). Команда выведет ключ двухфакторной аутентификации (TOTP) и резервные коды.

## Остановка локального демо

В окне консоли, где запущен `START_DEMO.cmd` или `npm run demo:local`, нажмите `Ctrl+C`. Скрипт корректно остановит Node.js процессы и контейнер базы данных.
