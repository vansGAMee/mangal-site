# МАНГАЛ — Конструктор сайта заведения общепита

Автономный конструктор сайта для ресторанов, кафе, баров, шашлычных и сервисов доставки еды на базе **Next.js**, **PostgreSQL** и **Docker Compose**.

Проект разворачивается по модели **один клиент = одно заведение = один VPS**. Все настройки визуальной витрины, контакта и каталога изменяются владельцем через админку без правки кода.

---

## Возможности

- **Персонализация заведения**: Название, описание, телефон, адрес, график работы.
- **Главный экран (Hero)**: Настраиваемый заголовок, фоновое hero-изображение и логотип.
- **Цветовая схема**: Настройка основного цвета, фона, текста и кнопок действий.
- **Социальные сети**: Прямые ссылки на VK, Telegram, WhatsApp.
- **Каталог товаров**: Категории, блюда, описания, цены, изображения.
- **Административная панель**: Защищённый вход с двухфакторной аутентификацией (**MFA / TOTP** Google Authenticator) и кодами восстановления (Recovery Codes).
- **Автономная инфраструктура**: PostgreSQL, Caddy с автоматическим HTTPS (Let's Encrypt), изолированная сеть Docker и постоянные объёмы (Named Volumes) для файлов.
- **Резервное копирование**: Готовые скрипты снятия и восстановления дампов БД и медиа-загрузок.

---

## Архитектурные ограничения

- **Однозадачность**: Одно развёртывание обслуживает строго один ресторан / кафе. Для нового заведения разворачивается отдельный VPS-контур.
- **Без внешней облачной зависимости**: Хранение базы данных и картинок локальное, на сервере VPS. Без зависимостей от S3 или SaaS-платформ.
- **Оплата**: Эквайринг Т-Банк / ЮKassa подключается опционально по договору. По умолчанию работает прямая передача заказов.

## Быстрый запуск локально (Windows / PowerShell)

1. Создайте `.env` из примера:
   ```powershell
   Copy-Item .env.example .env
   ```
2. Запустите локальный стек в Docker:
   ```powershell
   docker compose --env-file .env up -d --build
   ```
3. Примените миграции базы данных:
   ```powershell
   docker compose exec platform npx prisma migrate deploy
   ```
4. Откройте в браузере:
   - **Витрина**: `http://localhost`
   - **Админка**: `http://localhost/admin/login`

## Структура проекта

- `apps/platform`: Backend API, база данных Prisma, панель управления администратора `/admin`.
- `apps/storefront`: Клиентская витрина для покупателей `/`.
- `docker/`: Конфигурация Caddy (`Caddyfile`) и контейнеров.
- `packages/contracts`: Zod-схемы валидации данных и профиля заведения.
- `prisma/`: Схема базы данных `schema.prisma` и миграции.
- `scripts/`: Скрипты резервного копирования (`backup-vps.sh`, `restore-vps.sh`) и инициализации клиентом (`create-client.ts`).

## Безопасность и хранение секретов

Никогда не коммитьте в Git:
- `.env` и `.env.production`
- Настоящие ключи шифрования, пароли базы данных и TOTP-секреты.
- Папку с резервными копиями `backups/` и файлы загрузок `/app/uploads`.

В репозитории разрешено хранить только файлы-примеры с шаблонами: `.env.example`, `.env.production.example`.
